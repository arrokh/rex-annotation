## Report a vulnerability

[Report a vulnerability privately on GitHub](https://github.com/arrokh/rex-annotation/security/advisories/new).
You can also use **Report a vulnerability** on the repository’s
[Security tab](https://github.com/arrokh/rex-annotation/security).

If you cannot use the private form, open an
[issue](https://github.com/arrokh/rex-annotation/issues/new) asking for a private
contact method. Do not include vulnerability details in the public issue.

In private, include the affected versions, impact, and the smallest reproduction
you can share. Use synthetic replies or transcripts whenever possible. Do not
share credentials, account data, or private session contents.

For ordinary setup problems, use [troubleshooting](setup.md#common-fixes) or
the [bug report guide](CONTRIBUTING.md#report-a-bug).
