## Report a vulnerability

If GitHub offers **Report a vulnerability** on the repository’s
[Security tab](https://github.com/arrokh/rex-annotation/security), use that
private form. If the form is unavailable, open an
[issue](https://github.com/arrokh/rex-annotation/issues/new) asking the maintainer
for a private way to contact them. Do not include the vulnerability details in
that public issue.

In private, include the affected versions, impact, and the smallest reproduction
you can share. Use synthetic replies or transcripts whenever possible. Do not
share credentials, account data, or private session contents.

For ordinary setup problems, use [troubleshooting](setup.md#common-fixes) or
the [bug report guide](CONTRIBUTING.md#report-a-bug).
