Keyboard help
j/k and Enter: browse and open. /: filter replies or search reply text; \n / \N: repeat line search.
h/j/k/l, w/b: move. v/V: select characters or blocks. Enter: note. n/N: jump between notes. Ctrl+E: edit. Ctrl+W: wrap, if the host passes it through.
p: preview. y: copy. s/S: simulate delivery. Esc/q: back. Browser bindings are a subset, not a full Vim engine.
